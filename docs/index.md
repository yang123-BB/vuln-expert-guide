# 🛡️ 漏洞挖掘专家

> 从零开始，系统学习漏洞挖掘与利用技术

---

## 📚 课程简介

本课程系统讲解漏洞挖掘的完整知识体系，从基础环境搭建到高级利用技术，涵盖 Web 漏洞、二进制漏洞、内核漏洞、恶意软件分析等核心领域。

**适合人群**：
- 🔰 安全爱好者（希望入门漏洞研究）
- 🔧 安全工程师（希望提升技能）
- 🎓 计算机专业学生（希望深入学习）

**学习周期**：3-6 个月  
**课程章节**：18 章  
**总字数**：约 70 万字

---

## 🗺️ 课程大纲

### 📖 基础篇（第1-6章）

| 章节 | 标题 | 内容 |
|------|------|------|
| 第1章 | 漏洞研究之道 | 漏洞定义、分类、学习路径 |
| 第2章 | 搭建环境 | VMware、Ubuntu、IDA、Ghidra、AFL++ |
| 第3章 | C/C++与汇编 | 指针、内存管理、x86-64 汇编 |
| 第4章 | 内存模型 | 虚拟内存、栈/堆、ASLR、DEP |
| 第5章 | 逆向工程基础 | IDA Pro、Ghidra、反编译 |
| 第6章 | 动态分析 | GDB、WinDbg、strace、ltrace |

### 🔥 核心篇（第7-13章）

| 章节 | 标题 | 内容 |
|------|------|------|
| 第7章 | 漏洞分类与原理 | 栈溢出、堆溢出、UAF、条件竞争 |
| 第8章 | Fuzzing 技术 | AFL++、libFuzzer、Honggfuzz |
| 第9章 | 静态分析 | 代码审计、补丁分析、符号执行 |
| 第10章 | Web 漏洞（上） | SQL 注入、XSS、CSRF、SSRF |
| 第11章 | Web 漏洞（下） | 反序列化、XXE、文件上传、RCE |
| 第12章 | 二进制利用（上） | ROP、Ret2Libc、Stack Canary 绕过 |
| 第13章 | 二进制利用（下） | 堆利用、House of Series、tcache |

### 🚀 高级篇（第14-18章）

| 章节 | 标题 | 内容 |
|------|------|------|
| 第14章 | 内核漏洞挖掘 | LPE、KASLR 绕过、Syzkaller |
| 第15章 | 恶意软件分析 | 静态/动态分析、脱壳、YARA 规则 |
| 第16章 | 漏洞披露 | 负责任披露、CVE 申请、报告编写 |
| 第17章 | 实战：挖掘 CVE | 选择目标、Fuzzing、利用编写 |
| 第18章 | 职业发展 | 成长路径、个人品牌、技术面试 |

## 🎯 学习目标

完成本课程后，你将能够：

- ✅ 独立搭建漏洞研究环境（虚拟机、工具链）
- ✅ 使用 Fuzzing、代码审计、补丁分析等技术挖掘漏洞
- ✅ 分析 Web 漏洞、二进制漏洞、内核漏洞
- ✅ 编写漏洞利用脚本（PoC/Exploit）
- ✅ 负责任地披露漏洞（CVE 申请、报告编写）
- ✅ 规划漏洞研究职业发展路径

## 📅 学习建议

**第1个月**：完成基础篇（第1-6章）
- 搭建环境、学习 C/汇编、掌握逆向工具

**第2个月**：完成核心篇（第7-10章）
- 理解漏洞原理、学习 Fuzzing、挖掘 Web 漏洞

**第3个月**：完成核心篇（第11-13章）
- 学习二进制利用、堆利用、ROP 链构造

**第4-6个月**：完成高级篇（第14-18章）
- 研究内核漏洞、分析恶意软件、挖掘真实 CVE
